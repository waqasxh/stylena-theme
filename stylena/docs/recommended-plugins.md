# Recommended Plugins

Appearance > Install Plugins lists these. The theme works without the optional ones.

| Plugin | Status | Purpose |
| --- | --- | --- |
| Stylena Core | Required (bundled) | Services, Team, Portfolio, FAQ, Slider content types, taxonomy, shortcode, widgets |
| One Click Demo Import | Optional | Imports the sample site ([Demo import](demo-import.md)) |
| Contact Form 7 | Optional | Contact forms; the demo import creates a sample form when it is active |
| Yoast SEO | Optional | Search engine optimisation (title tags, sitemaps, schema). Not installed by the demo import |

Optional plugins install from WordPress.org and are governed by their own licences and privacy terms. Stylena adds no tracking or analytics of its own.
