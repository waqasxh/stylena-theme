## Reporting a bug

Send: Stylena version, WordPress and PHP versions, active plugins, exact error text, steps to reproduce, and a link or screenshot. Never send passwords or API keys. First read `troubleshooting.md` and `faq.md`.

Updates for compatibility and fixes are delivered through the channel you bought from (ThemeForest downloads, or the zylonex.com account for direct sales).
