# Hero Video and Poster

Appearance > Customize > Stylena Theme Options > Hero Section.

- **Hero Poster Image**: static background of the homepage hero. Shown immediately, and as the fallback if no video is set or the video fails to load. Recommended 1920x1080 or larger.
- **Hero Video** (optional): upload an MP4 (H.264), 1920x1080 or higher, ideally under 10 MB. It is muted, loops, and loads lazily after the page (it is not preloaded), so it does not block page load.
- Leave Hero Video empty to show only the poster. The theme ships no default video.

Tips
- Compress the video (short loop, no audio track needed, 24-30 fps).
- Use a poster that matches the first frame to avoid a visible jump.
- The demo import sets a sample AI-generated poster and a looping animation made from it (downloaded from the demo server; see [Demo import](demo-import.md)). Replace both with your own media.
- Only use video and images you have the rights to.
