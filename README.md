# Stylena

Stylena is a WordPress theme for beauty and wellness businesses (salons, spas, clinics): full-width hero with optional background video, services, team, portfolio, reviews, FAQ and image sliders.

- Version 1.3.0, WordPress 6.8+, PHP 8.1+
- Licence: GPL-2.0-or-later (see `LICENSE`)
- Author: [Zylonex](https://zylonex.com)
- Live demo: https://stylena.zylonex.com

## What is in this repository

| Folder | Contents |
| --- | --- |
| `stylena/` | The theme. Copy to `wp-content/themes/` (or zip the folder and upload it under Appearance > Themes). |
| `stylena-core/` | Companion plugin (Services, Team, Portfolio, FAQ and Slider content types). Install and activate it before importing demo content. |
| `stylena-demo-content/` | Optional demo import files. Upload the folder to `wp-content/uploads/` and rename it to `stylena-demo`, then use Appearance > Import Demo Data (One Click Demo Import). |

Documentation is in `stylena/docs/`. The changelog is `stylena/changelog.txt`.

## AI-generated media

The sample photographs, hero video and `screenshot.png` of the demo were generated with Google Gemini and are not part of the theme package, except the preview `screenshot.png`. See `stylena/docs/ai-disclosure.md`.
